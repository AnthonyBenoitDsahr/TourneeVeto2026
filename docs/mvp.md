# TournéeVéto — périmètre du POC (5 jours)

Périmètre priorisé pour une équipe .NET : application Blazor WebAssembly statique sur GitHub Pages, sans backend ni comptes. IndexedDB est le stockage local de référence. Une tournée complète doit pouvoir être préparée, réalisée, conservée et consultée sur une tablette sans réseau. Données fictives et règles métier simplifiées; ce POC ne remplace pas un dossier médical ni un avis clinique.

## Risques produit

1. **Perte ou effacement des données locales :** IndexedDB est propre à l’appareil et au navigateur; suppression des données, changement d’appareil ou politique du navigateur peut rendre visites et rapports inaccessibles. Le POC ne fournit ni sauvegarde distante ni synchronisation.
2. **Disponibilité hors ligne incomplète :** une première ouverture jamais effectuée en ligne, un cache incomplet ou une configuration incorrecte du chemin GitHub Pages peut empêcher le parcours de démarrer en bâtiment. Valider le test hors ligne sur l’URL réellement déployée et sur la tablette cible.
3. **Confiance excessive dans un POC simplifié :** données et règles fictives pourraient être interprétées comme des consignes cliniques. Signaler clairement le caractère de démonstration et faire valider contenu et vocabulaire par un vétérinaire laitier avant tout usage réel.
